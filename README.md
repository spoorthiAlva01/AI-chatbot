# AI-chatbot

This project uses the OpenAI Python client and requires an API key to run.

## Setup

1. Create a `.env` file in the project root.
2. Add your OpenAI API key:

```env
OPENAI_API_KEY=your_openai_api_key_here
```

3. Install dependencies if needed:

```bash
pip install openai python-dotenv
```

4. Run the chatbot:

```bash
python app.py
```

> If you prefer, you can also set `OPENAI_API_KEY` or `OPENAI_ADMIN_KEY` directly in your OS environment variables.
